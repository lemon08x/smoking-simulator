# 「戒一根」下一版本玩法方案

## 一句话说明

这是一个娱乐化吸烟模拟器：保留自由吸烟玩法，新增 45 秒呼吸节奏玩法；自由模式按普通规则发奖，节奏模式则根据六轮操作成绩发放 0～4 倍碎片，并继续积累烟盒抽卡。

## 核心循环

```text
点一根
  ↓
选择玩法
  ├─ 自由模式：按住吸烟，松开吐烟
  └─ 节奏模式：跟随振动按住吸入、提示吐出时松开，持续 45 秒
  ↓
香烟燃尽，自动结算
  ↓
翻开本局奖励
  ↓
获得烟标碎片 / 幸运加倍 / 免费抽卡
  ↓
抽烟盒，或再来一根
```

整个流程以轻量、即时反馈和收集乐趣为主，不增加烟瘾评估、成功确认或复杂健康任务。

## 两种玩法

### 自由模式

沿用当前核心交互：

- 按住屏幕时吸烟，火光增强，香烟缩短。
- 松开时吐出烟雾，并累计一口。
- 累计吸够一根后自动进入结算。
- 用户可以控制每一口的长短和节奏。

自由模式适合想直接体验现有吸烟动画的用户。

### 节奏模式

新增一个固定约 45 秒的轻互动模式：

- 香烟按照时间自动燃烧。
- 振动开始时提示按住吸烟。
- 振动停止时提示松开吐烟。
- 用户在吸入提示出现时按住，在吐出提示出现时松开。
- 每次松开立即显示本轮 `PERFECT / GOOD / BAD` 反馈。
- 45 秒结束后香烟燃尽并自动结算。
- 漏掉一次节奏不会卡住燃烧，但会降低最终成绩和奖励。

六轮操作共同决定本局成绩：

| 最终成绩 | 综合节奏分 | 碎片奖励 |
|---|---:|---:|
| PERFECT | ≥ 85% | 普通奖励 ×4 |
| GREAT | ≥ 65% | 普通奖励 ×3 |
| GOOD | ≥ 40% | 普通奖励 ×2 |
| BAD | < 40% | 无奖励 |

按下和松开的时机都会计分。越接近提示切换点分数越高；没有操作的轮次记为 0 分。

节奏模式不是严肃训练课程，而是带有呼吸节奏感的另一种吸烟玩法。

## 自动结算

两种模式都不询问用户是否“成功戒掉”。香烟燃尽后直接进入结算：

```text
第 12 根 · 已燃尽
吸了 6 口 · 用时 45 秒

[翻开本局奖励]
```

结算只统计本次娱乐体验，不把完成次数直接解释为真实少抽数量或医学收益。

## 每局短奖励

当前每 20 根才获得一次开盒，前期反馈较慢。下一版本在每局结束时增加一次 1～2 秒的翻牌：

- 自由模式固定获得 `烟标碎片 ×1`，并可能触发碎片加倍或免费单抽。
- 节奏模式不再抽随机加成，直接按最终成绩获得 `×4 / ×3 / ×2 / ×0` 碎片。
- 第一次获得有效奖励时，赠送一次免费单抽。
- `BAD` 不获得碎片、首次免费抽，也不推进 20 次保底进度。

首版建议节奏：

| 条件 | 奖励 |
|---|---|
| 完成一根自由模式 | 烟标碎片 ×1，并翻开一次随机加成 |
| 完成一根节奏模式 | 按 PERFECT / GREAT / GOOD / BAD 发放 4 / 3 / 2 / 0 个碎片 |
| 集齐 5 个碎片 | 单抽一次 |
| 第一次获得有效奖励 | 免费单抽一次 |
| 累计 20 次有效完成 | 额外获得一次保底稀有开盒 |

准确概率作为可配置参数，先通过试玩调整，不在页面流程中增加复杂说明。

## 抽卡与收藏

烟盒抽卡继续作为主要长期奖励：

- 首版复用现有 8 款烟盒皮肤。
- 后续可以加入香烟外观、烟雾颜色和燃烧特效。
- 普通、稀有、传说继续沿用当前 60% / 30% / 10% 的基础概率。
- 重复烟盒保留 `×N` 收藏数量，并返还少量烟标碎片。
- 累计 20 次有效完成获得的开盒至少为稀有，形成“一整包”的阶段奖励。

抽到的烟盒可以继续改变下一次吸烟时的烟盒、香烟和烟雾表现，但不增加复杂卡组或数值能力。

## 首版范围

首版只做完整核心循环：

1. 首页增加自由模式和节奏模式选择。
2. 保留现有自由模式。
3. 实现 45 秒振动节奏模式。
4. 两种模式统一自动结算。
5. 自由模式随机发奖，节奏模式按四档成绩发奖。
6. 实现 5 碎片单抽、首次有效奖励免费抽和 20 次有效完成保底稀有。
7. 复用现有烟盒收藏和换肤。

暂不加入复杂健康记录、烟瘾问卷、互动卡组、余烬币商店、排行榜或付费抽卡。

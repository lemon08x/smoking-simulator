# 「戒一根」可试玩版测试方案

## 测什么

这轮只守住完整试玩闭环：

```text
选择模式 → 完成一根 → 自动结算 → 翻奖励
→ 免费抽或碎片抽 → 获得烟盒 → 换肤后再玩
```

重点检查四件事：

- 自由模式没有被新玩法改坏。
- 节奏模式可以稳定运行约 45 秒。
- 完成、奖励和抽卡都不会重复结算。
- 老用户的累计数据与烟盒不会丢失。

## 快速测试

不打开微信开发者工具也能先跑两组测试：

```powershell
node tests/unit.test.js
node tests/page.test.js
```

- `unit.test.js`：计时、会话、碎片、免费抽、保底池、重复返还和迁移。
- `page.test.js`：首页选模式、两种吸烟页面、结算、收藏与抽卡串联。

提交前两组必须全部通过。

## 开发者工具全链路

先在微信开发者工具的“设置 → 安全设置”中开启服务端口，然后启动自动化端口：

```powershell
& 'C:\Program Files (x86)\Tencent\微信web开发者工具\cli.bat' auto `
  --project 'C:\Users\94202\Desktop\github\smoking-simulator' `
  --auto-port 9420
```

在安装了 `miniprogram-automator` 的环境运行：

```powershell
node tests/automator/verify.js
```

它会验证：

- 首页模式选择和奖励账户。
- 自由模式完成、结算和翻牌。
- 首局免费抽与换肤。
- 节奏模式进入和统一结算。
- 整包保底不出现普通烟盒。
- 收藏、统计、设置和首页联动。
- 全程没有 console error 或 exception。

脚本结束后会清空测试数据并回到首页。

## 专项测试

```powershell
node tests/automator/verify-burn.js
node tests/automator/verify-rhythm.js
node tests/automator/fps.js
```

- `verify-burn.js`：检查自由模式烟支缩短方向和结算前清场。
- `verify-rhythm.js`：真实等待约 45 秒，确认按时燃尽并自动结算。
- `fps.js`：观察自由模式静止和烟雾较多时的平均帧率。

## 真机试玩清单

自动化通过后，再用 iOS 和 Android 各试玩一次：

- [ ] 吸入阶段振动容易理解，吐出阶段没有残留振动。
- [ ] 切后台、锁屏或离开页面后立即停止振动。
- [ ] 关闭系统振动时也能仅靠画面理解节奏。
- [ ] 自由模式按住和松开仍然跟手。
- [ ] 小屏没有按钮、结算卡或翻牌内容溢出。
- [ ] 第一根结束能看到碎片并立即免费抽一次。
- [ ] 连点翻牌和抽卡不会重复发奖或扣资源。
- [ ] 换上的烟盒能影响下一根烟的颜色。

## 可试玩版通过标准

- Node 逻辑与页面测试全部通过。
- 微信开发者工具全链路通过。
- 真实 45 秒节奏测试通过。
- 没有重复结算、重复发奖或扣资源未得烟盒。
- 至少完成一台真机的振动体验检查。

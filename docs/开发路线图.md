# 「戒一根」下一版本开发路线图

## 目标

用较小的改动完成下面这条新玩法闭环：

```text
双模式吸烟 → 自动结算 → 每局短奖励 → 烟盒抽卡 → 换肤后再玩
```

开发分为三个实现 PR，每个 PR 都可以单独试玩和验收。

## 开始开发前

先完成两件事：

1. 维护者确认双模式和短奖励方向。
2. 用简单分镜确认 45 秒节奏模式与结算翻牌的节奏。

不需要先建设复杂的数据平台或健康体系。

## PR 1：双模式吸烟

### 要做什么

- 首页点击「点一根」后选择自由模式或节奏模式。
- 自由模式保留现有按住吸烟、松开吐烟。
- 节奏模式持续约 45 秒。
- 振动开始提示吸烟，振动停止提示吐烟。
- 节奏模式中的香烟按时间自动燃烧。
- 两种模式结束后进入同一个结算页面。

### 完成标准

- 两种模式都能完整烧完一根。
- 节奏模式漏掉一次操作也不会卡住。
- 页面进入后台后不会继续振动或残留动画。
- 同一根烟只结算一次。

## PR 2：短奖励与抽卡节奏

### 要做什么

- 每局结算后增加翻牌动画。
- 每局固定发放一个烟标碎片。
- 支持碎片加倍和小概率免费单抽。
- 第一次完成赠送免费单抽。
- 5 个碎片可以进行一次单抽。
- 累计 20 根额外获得一次保底稀有开盒。
- 重复烟盒返还少量碎片。

### 完成标准

- 用户完成第一根就能体验一次抽卡。
- 每局结束都有可见奖励。
- 奖励不会因为重复点击发放多次。
- 抽卡失败时不会丢失碎片或次数。
- 现有烟盒收藏可以继续使用。

## PR 3：收藏与体验完善

### 要做什么

- 让不同烟盒继续改变烟盒、香烟和烟雾配色。
- 增加少量烟雾或燃烧特效奖励。
- 优化模式选择、结算和翻牌动画。
- 补充音效、振动开关和低动态效果。
- 完成单元测试、全链路测试和真机试玩。

### 完成标准

- 新奖励能在下一局明显出现。
- 自由模式的现有手感没有退化。
- 45 秒节奏模式在不同设备上节奏稳定。
- 单测和核心自动化稳定通过。

## 开发顺序

```text
双模式页面与状态
  ↓
节奏计时和振动
  ↓
统一结算
  ↓
每局翻牌奖励
  ↓
碎片与抽卡
  ↓
收藏联动和视觉完善
```

## 重点测试

- 自由模式按住、松开和烧完。
- 节奏模式的 45 秒计时与振动启停。
- 切后台、返回和中途退出。
- 重复点击结算或抽卡。
- 首次免费抽、5 碎片单抽和 20 根保底。
- 重复烟盒返还碎片。
- 旧烟盒收藏升级后仍然存在。

## 暂不开发

- 烟瘾强度评估和成功确认。
- 追加多轮呼吸训练。
- 互动卡、场景卡和手动卡组。
- 复杂保底、星级升级和兑换商店。
- 医疗统计、排行榜和付费抽卡。

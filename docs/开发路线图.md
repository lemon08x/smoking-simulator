# 「戒一根」下一版本开发路线图

## 目标

用较小的改动完成下面这条新玩法闭环：

```text
双模式吸烟 → 自动结算 → 每局短奖励 → 烟盒抽卡 → 换肤后再玩
```

当前功能全部在同一个 PR #1 分支中按阶段实现和验收，不拆分新的开发 PR。

## 开始开发前

先完成两件事：

1. 维护者确认双模式和短奖励方向。
2. 用简单分镜确认 45 秒节奏模式与结算翻牌的节奏。

不需要先建设复杂的数据平台或健康体系。

## 阶段 1：双模式吸烟

### 要做什么

- 首页点击「点一根」后选择自由模式或节奏模式。
- 自由模式保留现有按住吸烟、松开吐烟。
- 节奏模式持续约 45 秒。
- 振动开始提示按住吸入，振动停止提示松开吐出。
- 记录六轮按下和松开时机，并给出即时反馈。
- 节奏模式中的香烟按时间自动燃烧。
- 两种模式结束后进入同一个结算页面。

### 完成标准

- 两种模式都能完整烧完一根。
- 节奏模式漏掉一次操作也不会卡住。
- 六轮操作能稳定汇总为 PERFECT / GREAT / GOOD / BAD。
- 页面进入后台后不会继续振动或残留动画。
- 同一根烟只结算一次。

## 阶段 2：分档奖励与抽卡节奏

### 要做什么

- 每局结算后增加翻牌动画。
- 自由模式保留固定碎片、随机加倍和小概率免费单抽。
- 节奏模式按成绩发放 4 / 3 / 2 / 0 个碎片。
- 第一次有效完成赠送免费单抽。
- 5 个碎片可以进行一次单抽。
- 累计 20 次有效完成额外获得一次保底稀有开盒。
- 重复烟盒返还少量碎片。

### 完成标准

- 用户第一次获得有效奖励后就能体验一次抽卡。
- `BAD` 明确显示无奖励，且不推进免费抽和保底。
- `PERFECT` 得到普通碎片的 4 倍奖励。
- 奖励不会因为重复点击发放多次。
- 抽卡失败时不会丢失碎片或次数。
- 现有烟盒收藏可以继续使用。

## 阶段 3：收藏与体验完善

### 要做什么

- 让不同烟盒继续改变烟盒、香烟和烟雾配色。
- 增加少量烟雾或燃烧特效奖励。
- 优化模式选择、结算和翻牌动画。
- 补充音效、振动开关和低动态效果。
- 完成单元测试、全链路测试和真机试玩。

### 完成标准

- 新奖励能在下一局明显出现。
- 自由模式的现有手感没有退化。
- 45 秒节奏模式在不同设备上节奏稳定。
- 单测和核心自动化稳定通过。

## 开发顺序

```text
双模式页面与状态
  ↓
节奏计时、振动和按压评分
  ↓
统一结算
  ↓
分档翻牌奖励
  ↓
碎片与抽卡
  ↓
收藏联动和视觉完善
```

## 重点测试

- 自由模式按住、松开和烧完。
- 节奏模式的 45 秒计时、振动启停和六轮评分。
- PERFECT / GREAT / GOOD / BAD 的边界与奖励倍数。
- `BAD` 不发资源且不推进有效完成次数。
- 切后台、返回和中途退出。
- 重复点击结算或抽卡。
- 首次免费抽、5 碎片单抽和 20 根保底。
- 重复烟盒返还碎片。
- 旧烟盒收藏升级后仍然存在。

## 暂不开发

- 烟瘾强度评估和成功确认。
- 追加多轮呼吸训练。
- 互动卡、场景卡和手动卡组。
- 复杂保底、星级升级和兑换商店。
- 医疗统计、排行榜和付费抽卡。
